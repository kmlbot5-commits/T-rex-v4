# Trex 🦖 AI — Free Mode

This version does NOT require a video API key.

It generates high-quality video prompts and provides buttons to open external AI video creators. The external service's own free-credit limits, account requirements, and availability still apply.

## Deploy on Render
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- No environment variables are required.

## Important
This version cannot secretly generate videos on Render without a video-generation API. Do not add an API key to the frontend.
